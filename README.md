# 咸鱼报价机器人微信客户端使用文档

## 软件介绍

专为微信群聊设计的链上资产报价工具，可实时查询Token链上信息。通过监听指定群聊消息，自动响应成员查询请求并提供最新市场数据。

## ⚠️使用前警告：受微信风控影响，微信账号会有被封控的概率，请各位在使用时做好斟酌！

### ⚠️要监控的群组名称尽量不要有特殊符号和emoji，更不要有空格，会报错退出。

## 安装说明

1. **下载程序包**  
   获取压缩包后，右键选择【解压到当前文件夹】

2. **选择安装路径**  
   ▸ 将解压后的文件夹移动至`C:\Program Files\`或其它**纯英文路径**的目录  
   ▸ 注意：路径中严禁包含中文/空格/特殊符号

3. **安全设置**  
   ▸ 退出360安全卫士、腾讯电脑管家等国产杀毒软件  

## 使用说明

1. **前期准备**  
   - 在目标电脑上登录微信PC版（需保持常驻登录）
   - 确保网络连接同时满足：  
     ✓ 微信客户端使用国内IP  
     ✓ 配置全局代理访问使之可访问外网（需挂梯子）
2. **启动机器人**
   - 双击运行解压目录中的exe文件
3. **配置监控**
   1. 在机器人控制面板点击【添加群聊】
   2. 手动双击打开每个待监控的微信群窗口（需保持窗口开启状态）
   3. 重复操作直至添加所有目标群组
4. **开始监听**
   - 点击【启动服务】按钮
   - 观察日志窗口显示`监听已启动`提示
   - 在群内发送测试指令验证响应

## 注意事项

‼️ **重要安全提醒**

- 推荐不要在主力工作电脑运行本程序，使用本程序时，程序会独占此设备，影响其他操作。推荐使用：
  - 专用备用机
  - VMware/VirtualBox虚拟机
  - 云服务器（需配备图形界面）

⚙️ **运行环境要求**

- 保持微信窗口始终置顶（最小化可能导致监听失效）
- 代理工具需配置全局模式（建议使用Clash for Windows）

- 遇到程序无响应时：  
  1. 强制结束进程  
  2. 检查目录下wx_bot.log日志文件
  3. 重新启动程序
